Setup Instructions

On each ward device:

  1. Install the project and model file
  2. Run: python run.py
  3. Note the device's IP address
  4. Ensure the device stays connected to WiFi/LAN

Find IP address:

Windows:
ipconfig
Look for:
IPv4 Address. . . : 192.168.1.XX

Add Camera Device
